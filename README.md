## Hi! I'm Luc 👋
I'm a Computer Science student at Northeastern University, passionate about AI, machine learning, and aerospace.

## 📁 Notable Projects
- __Lottery Ticket Application (Python and iOS):__ Developed an automated lottery ticket checker using computer vision and deep learning, training a PyTorch ResNet18 CNN to classify lottery ticket types (Powerball, Mega Millions, Lotto America, EuroMillions) and building an OCR pipeline using EasyOCR and OpenCV to extract numbers and draw dates from ticket photos, while integrating historical draw data via the Lottery Data API for win detection. Separately developed a companion iOS app in Swift replicating the core pipeline on-device using Apple's Vision framework, CoreML, and SwiftData.
- __Gradient Boosting & RNN Exoplanet Transit Detector:__ Designed a Gradient Boosting classifier and regression-tree/tree-node classes from scratch, reaching a ROC-AUC of 0.969 and 91.8% accuracy detecting exoplanet transits across 6,640 NASA Kepler light curves, alongside a PyTorch RNN trained on raw light-curve data (0.880 ROC-AUC, 80.9% accuracy). Applied both models to 1,574 stars with unconfirmed exoplanet candidates, flagging 441 as likely exoplanets and identifying 70 objects that NASA's automated vetting scored as planets but the models scored as eclipsing binaries.
- __Fantasy English Premier League (FPL) Optimizer (v1.0 - v3.0):__ Built and deployed 2 generations of algorithms to manage an FPL squad using live data from the official FPL API, with weighted scoring logic that ranked team selections in the top 25% of all FPL players over 2 seasons. Rebuilt the system (v3.0) using a PyTorch network to project long-term expected points and an XGBoost regressor for short-term stats (goals, assists, minutes), currently live-testing for the 2026/27 season.
- __Calendar Application:__ Collaboratively developed a Java-based calendar application using the MVC architecture and various object-oriented design patterns _(code upon request)_.
